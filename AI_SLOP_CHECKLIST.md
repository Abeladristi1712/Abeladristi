# AI SLOP CHECKLIST

Before publishing, check the following.

## Generic patterns
- [ ] The homepage does not begin with "Hi, I'm..." unless there is a deliberate reason.
- [ ] There is no decorative gradient without a reason.
- [ ] There is no generic row of 3-4 rounded cards.
- [ ] Glassmorphism is not being used simply because it "looks modern."
- [ ] Pills/tags are not everywhere.
- [ ] Not every section is centred.
- [ ] There are no generic icons beside every heading.
- [ ] There are no meaningless skill progress bars.
- [ ] There are no fake testimonials or invented claims.
- [ ] Animations have a design purpose.
- [ ] Sections do not all use exactly the same rhythm.
- [ ] The site does not accidentally look like a SaaS landing page.

## Reference fidelity
- [ ] I can point to a specific reference behind the typography.
- [ ] I can point to a specific reference behind the composition.
- [ ] I can explain the image treatment.
- [ ] My distinctive design move is visible.
- [ ] I translated design principles rather than cloned another site.

## Identity
- [ ] The site reflects my actual content.
- [ ] The first screen feels specific to me.
- [ ] The hierarchy fits the kind of work I want to show.
- [ ] The design would still work if unnecessary decoration disappeared.

## Final test

> **Could I swap my name and project images with another person's and nobody would notice?**

- [ ] NO - the site feels specific to me.

If YES: revise.
